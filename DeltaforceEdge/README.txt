Delta Force Code Helper for Microsoft Edge

Load or update the extension:
1. Open edge://extensions in Microsoft Edge.
2. Turn on Developer mode.
3. Choose Load unpacked and select D:\Delta force\DeltaforceEdge.
   If the extension is already loaded, choose Reload on its extension card.
4. Open or refresh the official Delta Force redeem page after signing in.

Paste the codes into the panel at the bottom right, one code per line. Commas
and semicolons are also accepted. Press Start to submit codes in order. Pause
takes effect after the code currently being submitted; Continue resumes the
list, and Stop ends the run after the current code finishes.

Sign in and complete any verification yourself. Review the result shown by the
redeem page for each code.
